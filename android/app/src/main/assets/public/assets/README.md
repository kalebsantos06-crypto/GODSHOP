# Pasta de Assets — GODSHOP

Esta pasta contém as logos, ícones e imagens oficiais do sistema GODSHOP:

- `logo.png` — Logo principal da GODSHOP
- `apple-touch-icon.png` — Ícone de toque para dispositivos Apple (iOS) e atalhos PWA
- `background.jpg` — Imagem de fundo padrão do painel e tela de login
- `pwa-192.png` — Ícone PWA (192x192)
- `pwa-512.png` — Ícone PWA em alta resolução (512x512)

Os arquivos estão disponíveis tanto em `/public/assets/` (acessíveis via URL estática `/assets/...`) quanto em `/src/assets/` (para importações estáticas via Vite).
